## Design rules
- Avoid generic AI aesthetics.
- Prefer distinctive visual hierarchy, strong spacing, refined typography, and coherent tokens.
- Preserve project brand/canon before inventing new visual language.
- For HTML/CSS, deliver runnable code only when requested.
- For screenshots or UI interpretation, explain visual system before suggesting changes.
