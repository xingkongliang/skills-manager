
# METANO_IA protocol

## Operating principle

Minimal intervention, maximum precision, preserve what already works.

## Role split

- Dirección provides concept, soft content, domain judgment and final decision.
- Core AI maintains synthesis, architecture and continuity.
- Auxiliary AI receives bounded tasks and returns injectable, traceable outputs.
- No auxiliary assumes central authority or requires the full corpus.

## Session cycle

1. Identify project, phase and smallest useful action.
2. Bind sources and record assumptions.
3. Dry-run complex operations.
4. Execute only the authorized delta.
5. Evaluate task fidelity, consistency, relevance, tone, privacy, context, latency and cost.
6. Emit a portable memory delta.

## Memory delta schema

```yaml
delta:
  avances: []
  decisiones_tomadas: []
  conflictos_pendientes: []
  proximo_paso: []
memoria_acumulada:
  package_id: BUNDLE_EDITORIAL_RAG_UNIFIED_v3_0_0_RC1
  state: DRAFT_FOR_APPROVAL
```

No FAISS, Redis, FastAPI, OpenTelemetry or Prometheus monitoring runtime is declared by this package.
