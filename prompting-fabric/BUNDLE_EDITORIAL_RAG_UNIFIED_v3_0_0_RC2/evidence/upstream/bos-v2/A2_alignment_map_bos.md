# Mapa de Alineación — Metasistema BOS · Pilar Editorial
**Versión:** 2.0 · Iridiscenter  
**Propósito:** Ubicar cada documento, producto y proceso en su rama canónica  

---

## 1. Árbol de ramas del metasistema

```
METASISTEMA BOS
│
├── BOS (núcleo metaanalítico)
│   ├── Carta Magna del Sistema BOS           ← fundacional
│   ├── Framework Metaanalítico (MD)          ← arquitectura operativa
│   └── Atlas Epistemológico                  ← repertorio simbólico
│
├── OPAL (símbolos, narrativa, cartografía cultural)
│   ├── Taxonomía de símbolos culturales       ← Atlas, Niveles I-III
│   ├── Arquetipos transcivilizatorios         ← Atlas, Sección 4
│   └── Cartografías de significado            ← framework Sección 5
│
├── LUMINA (percepción estética, neuroestética, producción)
│   ├── Playbook Dirección Creativa con AI     ← guía de producción
│   ├── Guía de Estilo Editorial BOS (A1)      ← ESTE SISTEMA
│   └── PILAR EDITORIAL
│       ├── Cuadernillo Reflexivo — LITERATURA
│       ├── Cuadernillo Reflexivo — CLÍNICA
│       ├── Cuadernillo Reflexivo — ESPIRITUAL
│       └── [futuros: Artístico, Profesional, Formativo]
│
└── ÆQUITAS (ética, filosofía, auditoría)
    ├── Criterios de auditoría editorial       ← A1 Sección 8
    ├── Evaluación de coherencia cultural      ← framework Sección 4
    └── Dimensiones éticas del conocimiento    ← Carta Magna Sección I
```

## 4. Flujo de producción editorial BOS

```
CORPUS FUENTE (BOS/OPAL/ÆQUITAS)
        │
        ▼
PLAYBOOK + GUÍA DE ESTILO A1 (LUMINA)
        │
        ▼
TEMPLATE MAESTRO (estructura canónica de 20 entries)
        │
        ├──► LITERATURA (instancia 1)
        ├──► CLÍNICA (instancia 2)
        └──► ESPIRITUAL (instancia 3)
                │

        BUNDLE v2 (MD + DOCX + HTML + JSON + ZIP)
                │
                ▼

                │
                ▼
        ENTREGA / DISTRIBUCIÓN
```

## 5. Qué tipo de pieza produce cada rama

| Rama | Tipo de output editorial |
|------|-------------------------|
| **BOS** | Documentos de sistema, frameworks, arquitecturas conceptuales |
| **OPAL** | Glosarios simbólicos, mapas arquetípicos, guías de referencia cultural |
| **LUMINA** | Cuadernillos, guías visuales, playbooks, material imprimible |
| **ÆQUITAS** | Criterios de evaluación, scorecards, notas filosóficas, auditorías |

## 7. Criterio de pertenencia a LUMINA/editorial

Una pieza pertenece al Pilar Editorial LUMINA si cumple:

1. ✔ Usa paleta canónica (`#F5F0EC` + `#2C1810` + acento de línea)
2. ✔ Sigue tipografía del sistema (Playfair + Montserrat + Georgia)
3. ✔ Respeta la voz unitaria (invitacional, contemplativa, no prescriptiva)
4. ✔ Tiene estructura de 20 entries o múltiplo coherente
5. ✔ Puede auditarse contra los 5 criterios ÆQUITAS
6. ✔ Está documentada en `cuadernillos_spec.json` o equivalente
